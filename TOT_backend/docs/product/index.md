# 产品类文档

此目录用于存放与“产品定义/需求口径/验收规则”相关的文档入口。

**产品需求口径**以 [`PRODUCT_REQUIREMENTS.md`](./PRODUCT_REQUIREMENTS.md) 为准（不写版本号时以仓库内该文件头部为准）。

当 **实现文档或 Spec 与 PRD 冲突** 时，先回到 PRD 确认产品意图，再同步修订 [`../specs/`](../specs/index.md) 或实现，避免 silent drift。
