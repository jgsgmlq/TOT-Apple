# 前端 Chat 回复卡片重设计

> 2026-05-20 | 分支: macstudio | 基于 FinalResponse 结构化输出 + 视觉脑暴

## 1. 目标

把 Executive Chat 前端回复从纯 Markdown 文本升级为结构化卡片渲染，覆盖：正常数据展示、HITL 追问交互、空数据/降级状态。

## 2. 卡片组件体系

LLM 输出结构化 JSON → 前端按字段驱动渲染组件，组件按固定顺序排列。

### 2.1 组件渲染顺序

```
1. 💭 思考过程 (可折叠，已有，不动)
2. 🎯 Hero 卡片 — 核心结论 (overview → hero)
3. 📊 图表 — 对比/趋势 (visualizations → 迷你柱状图/折线)
4. 📈 指标格 — 关键数字 (keyNumbers → 2-4列网格)
5. 📋 表格 — 漏斗/排名/名单 (table)
6. ⚡ 洞察 — 异常/亮点 (attentionPoints → 色条列表)
7. 💡 追问 — 下一步建议 (followUpSuggestions → chips)
8. 📝 数据溯源 — 口径+截止 (statisticsProvenance → 折叠小字)
```

### 2.2 Hero 卡片

```
┌─────────────────────────────────┐
│ 📊 iPad mini 常规周培训         │  ← 渐变紫底白字
│ 完成率 42.5%                    │
│ 17/40人 · 23人未完成 · 进度偏低  │
└─────────────────────────────────┘
```

- 数据来源：`overview` 字段
- 颜色：渐变紫 `#667eea → #764ba2`
- 始终显示，无 overview 时降级为灰色卡片

### 2.3 指标格子 (keyNumbers)

```
┌────────┬────────┬────────┬────────┐
│  40    │  17    │  23    │ 82.5%  │
│ 总人数  │ 已完成  │ 未完成  │ 学习率  │
└────────┴────────┴────────┴────────┘
```

- 2-4 列自适应网格
- 每个格子：数字大、标签小、带浅色背景
- 数字颜色按语义：完成=绿、未完成=红、中性=黑

### 2.4 表格 (table) — 两种样式

**漏斗数据 → 进度条 + 流失标注 (方案 C)**

```
📤 推送    ████████████████████ 40人·100%
              ↓ 流失 0人 (0%)
✅ 送达    ████████████████████ 40人·100%
              ↓ 流失 7人 (17.5%)
📖 学习中  ████████████████░░░░ 33人·82.5%
              ↓ 流失 16人 (48.5%)
🎯 已完成  ████████░░░░░░░░░░░░ 17人·42.5%
```

- 进度条宽度 = 占比
- 条之间红色小字标注流失人数和比例
- 颜色：推送=蓝、送达=绿、学习中=橙、已完成=红

**排名/名单/对比 → 紧凑表 (方案 A)**

```
| 任务 | 完成率 | 截止 |
| iPad mini | 42.5% | 05-28 |
| NPI 新品  | 47.5% | 06-01 |
```

- 标准 HTML table
- header 灰底，行间隔色
- `highlight` 支持标记 Top/Bottom N

### 2.5 洞察列表 (attentionPoints)

```
┌──────────────────────────────────┐
│ ⚠️ 完成率仅42.5%，超半数未完成    │  ← 橙底左边框
├──────────────────────────────────┤
│ ℹ️ 学习率82.5%，但转化率低        │  ← 蓝底左边框
├──────────────────────────────────┤
│ ✅ 触达率100%，通知无问题          │  ← 绿底左边框
└──────────────────────────────────┘
```

- warning=橙底橙左边框, info=蓝底蓝左边框, positive=绿底绿左边框
- 每条一个独立色块

### 2.6 追问建议 (followUpSuggestions)

```
[👥 未完成人员名单] [📈 完成率趋势] [🏪 各门店对比]
```

- 水平排列 chip 按钮
- 点击 = 发送该追问文本
- 颜色：浅紫底 `#e8eaf6`

### 2.7 数据溯源 (statisticsProvenance)

```
统计口径: 按任务总人数为分母 · 数据截止: 2026-05-20 19:22
```

- 卡片最底部，灰色小字，右对齐
- 始终显示

## 3. HITL 追问交互

### 3.1 缺任务参数 (missing_task_ref)

用户问"有哪些门店需要重点关注？"（没提任务）→ Agent 列出任务卡片让用户选：

```
┌─────────────────────────────────┐
│ 请问要查看哪个任务的预警门店？     │
│ 当前进行中的任务：               │
│ ┌─────────────────────────────┐ │
│ │ iPad mini 常规周培训         │ │  ← 可点击卡片
│ │ 完成率 42.5% · 截止 05-28    │ │
│ └─────────────────────────────┘ │
│ ┌─────────────────────────────┐ │
│ │ NPI 新品组合学习             │ │  ← 选中态：紫边框
│ │ 完成率 47.5% · 截止 06-01    │ │
│ └─────────────────────────────┘ │
│ 点击上方卡片查看预警详情          │
└─────────────────────────────────┘
```

- 卡片列表：每张卡片显示任务名+完成率+截止日期
- 点击选中 → 自动 resume 会话，传入选中的 task_id
- 用户也可直接输入文字回复

### 3.2 简单追问 (missing_context)

用户问"帮我查一下"→ Agent 追问并给 chip 选项：

```
请问要查询哪个任务的完成率？
[iPad mini 培训] [NPI 新品学习] [iPhone Air 复盘]
```

- Chips 点击 = 发送对应文本
- 用户可输入自定义回复

### 3.3 模糊指代 (vague_task_ref)

用户问"上次那个任务"→ Agent 列出最近讨论的任务：

```
您指的是哪个任务？最近讨论过的：
[iPad mini 培训] [NPI 新品]
或直接输入任务名称
```

## 4. 空数据 & 降级

### 4.1 工具返回空数据

```
┌─────────────────────────────────┐
│ 华东区暂无培训任务数据            │  ← 灰色卡片
│ 该区域当前没有已下发的培训任务     │
└─────────────────────────────────┘
[🔍 查看其他区域] [📋 全部任务列表]
```

- Hero 卡片变灰色中性风格
- overview 文本由 LLM 生成
- suggestions 引导用户换个范围

### 4.2 JSON 解析失败 — 降级 Markdown

- 纯文本渲染（同现有）
- 卡片底部加一行灰色小字：`⚡ 结构化渲染失败，已降级为文本模式`
- 只在开发环境显示，生产环境隐藏

### 4.3 思考过程 (已有，不动)

- 折叠区 `<n-collapse>` 标题"思考过程"
- 显示 reasoning 文本
- 流式时实时展开，完成后自动折叠
